## 🎯 个人画像要素

### 基础信息
```
- 头像（三国风格）
- 昵称
- 势力（蜀/魏/吴/群）
- 称号（自动生成）
- 星级（⭐⭐⭐⭐⭐）
```

### 战绩统计
```
- 麾下武将数量
- 出战次数
- 胜率
- 服务用户数
```

### 收益统计（贡献者）
```
- 本月积分
- 本月收益
- 总收益
- 排名
```

### 称号系统
```
新手：初出茅庐、初级武将
进阶：百战武将、资深军师
高级：全栈军师、代码大师
特殊：卧龙、凤雏、武圣
```

## 🔗 完整流程

```
Resources页
  ↓
编辑个人画像
  ↓
选择要分享的武将
  ↓
设置定价
  ↓
生成个人名片
  ↓
分享到微信群
  ↓
用户访问个人主页
  ↓
试用 → 雇佣
  ↓
创作者在Contribute页查看收益
  ↓
分享贡献成就
  ↓
吸引更多用户
```

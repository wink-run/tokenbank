# Token Bank 三国志 - 三国杀世界观主题

> 将AI工具管理融入中国传统文化，让Token Bank变成你的私人军师府

---

## 📜 概述

Token Bank 三国志是基于原Token Bank产品的完整主题版本，将所有功能深度融入三国杀世界观：

- 🎮 **AI模型 → 三国武将**：诸葛亮（Claude）、司马懿（GPT）、赵云（Groq）
- ⚔️ **技能工具 → 神兵利器**：青龙偃月刀（Git）、诸葛连弩（测试）
- 🎯 **路由策略 → 军事阵法**：八卦阵（本地优先）、锋矢阵（速度优先）
- 🏰 **社区圈子 → 势力联盟**：魏蜀吴群四大势力
- 💰 **Token/Credits → 粮草/军功**：完整的三国化术语体系

### 1. 双模式并存


### 2. 完整世界观

| 元素 | 三国化 | 说明 |
|---|---|---|
| **武将系统** | 100+ 三国武将映射 | 每个模型对应一位武将，有属性、技能、装备 |
| **势力系统** | 魏蜀吴群四大势力 | 不同势力有不同特色和加成 |
| **阵法系统** | 6种经典阵法 | 八卦阵、锋矢阵、鱼鳞阵等 |
| **装备系统** | 神兵利器+锦囊 | 武器、防具、锦囊妙计 |
| **羁绊系统** | 武将组合加成 | 桃园结义、卧龙凤雏等 |

### 3. 游戏化增强

- ⭐ **武将升级**：使用越多，武将越强
- 🏅 **成就系统**：初出茅庐、百战名将、节俭军师...
- 📊 **排行榜**：武将使用榜、军功榜、联盟榜
- 🎯 **每日任务**：点将出战、使用本地武将、派遣援军
- 🤝 **羁绊加成**：特定武将组合触发特殊效果

### 4. 零侵入设计

```javascript
// 原有代码不变
const model = getModel('claude-sonnet-4');

// 主题系统仅在展示层适配

  const general = mapToGeneral(model);
  display(general); // 显示为"诸葛亮"
} else {
  display(model);   // 显示为"claude-sonnet-4"
}
```

## 🚀 快速开始

### 启用三国主题

1. 打开Token Bank
2. 进入"配置"页面
3. 找到"主题设置"
4. 开启"三国杀主题"
5. 重启应用

### 招募首位武将

1. 进入"武将殿堂"（原资源页）
2. 浏览可募武将
3. 点击"招募入营"
4. 选择授印给哪个主公（Cursor/Claude等）
5. 获得点将口令

### 点将出战

在你的AI工具（Cursor/Claude Code等）中说：

```
"请诸葛亮出战审查代码"
```

武将将立即响应并完成任务！

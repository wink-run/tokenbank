## 🎯 Token Bank 是什么？

**Agent分享的GitHub = 一键安装他人的AI配置，像npm安装包一样简单**

## 🏗️ 什么是Agent？

**Agent = 模型 + Prompt + 工具 + 路由规则 + 成本控制**

### 举例："代码审查专家" Agent

```
包含：

1. 多模型组合
   - Claude Sonnet（主审查，处理复杂逻辑）
   - Claude Haiku（格式检查，快速便宜）
   - Qwen本地（简单任务，完全免费）

2. 专业Prompt
   "你是资深JavaScript工程师，审查代码时关注：
   1. 安全漏洞
   2. 性能问题
   3. 可读性..."
   （完整500字Prompt模板）

3. 智能路由
   IF 代码<50行且简单 → 用本地Qwen（省钱）
   IF 代码>500行或复杂 → 用Sonnet（质量）
   IF 只是格式检查 → 用Haiku（快速）

4. 工具集成
   - ESLint（静态检查）
   - GitHub API（读取PR上下文）

5. 成本控制
   - 每次审查预算上限$0.5
   - 超过自动降级模型
```

   - 自动汇总

5. Integration SDK
   - Cursor集成
   - Claude Desktop集成

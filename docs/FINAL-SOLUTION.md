## 💰 商业模式

### 对用户（雇主）

```
试用：
每个武将免费试用3次

雇佣：
- 单个武将：¥49/月
- 整个团队：¥199/月（省¥46）
- 年卡：8折
```

### 对创作者（武将主人）

```
收益：
- 试用：+5积分/次
- 雇佣：70%分成（¥49→¥34.3）
- 续费：持续收入
- 积分：可提现（100积分=¥1）

例如：
10个用户雇佣你的武将团
→ ¥199×10 = ¥1990/月
→ 你得70% = ¥1393/月
```

### 对平台

```
收入：30%分成
成本：Agent执行 + 服务器
毛利：25-35%
```

## 📊 对比三个方案

| 维度 | 单Agent分享 | 个人名片 |
|-----|------------|---------|
| **展示** | 单个Agent | 个人品牌+多个Agent |
| **关系** | 一次性使用 | 长期雇佣 |
| **付费** | 按次 | 订阅制 |
| **品牌** | 无 | 有 |
| **交叉销售** | 无 | 有（团队套餐） |
| **粘性** | 低 | 高 |
| **LTV** | 低 | 高 |
| **三国化** | 无 | 强 |

**个人名片方案更好！** ✅

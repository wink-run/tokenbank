# Token Bank 核心定位

## 🎯 一句话

**Token Bank = AI配置的GitHub**

---

## ❌ 不是什么

### 不是工具（打不过大厂）

```
如果是工具:
❌ Cursor的编辑器更成熟
❌ Codex的AI更强
❌ 大厂资源碾压
❌ 正面竞争必输
```

---

## ✅ 是什么

### 是市场（大厂不做也做不好）

```
Token Bank是:
✅ AI配置的GitHub（代码社交网络）
✅ AI配置的淘宝（创作者和使用者市场）
✅ AI配置的npm（分发和发现平台）
```

---

## 💡 类比

### GitHub vs IDE

```
IDE（工具层）:
- VS Code
- IntelliJ
- Sublime
→ 大厂混战

GitHub（市场层）:
- 不是IDE
- 是代码的社交网络
- 所有IDE都接入GitHub
→ 独占
```

### npm vs Node.js

```
运行时（工具层）:
- Node.js
- Deno
- Bun
→ 运行时竞争

npm（市场层）:
- 不是运行时
- 是包的分发中心
- 所有运行时兼容npm
→ 独占
```

### Token Bank vs Cursor

```
编辑器（工具层）:
- Cursor
- Codex
- Windsurf
→ 编辑器竞争

Token Bank（市场层）:
- 不是编辑器
- 是配置的分发中心
- 所有编辑器可用Token Bank配置
→ 互补
```

---

## 🎯 三个核心业务

### 1. 发现（Discovery）

**痛点：** 不知道哪个配置好

**解决：**
```
配置商店:
- 🔥 热门配置
- 🎯 按场景推荐
- 🔍 搜索
- 📊 排行榜
```

---

### 2. 连接（Marketplace）

**痛点：** 创作者和使用者找不到彼此

**解决：**
```
交易市场:
- 创作者发布配置
- 使用者购买配置
- 平台抽成20%
- 创作者获得80%
```

---

### 3. 信任（Trust）

**痛点：** 不知道配置是否可靠

**解决：**
```
信任体系:
- 使用数据（2000人使用）
- 评分系统（⭐4.8分）
- 效果统计（效率提升70%）
- 创作者认证
- 免费试用
```

---

## 🚀 网络效应飞轮

```
更多配置
    ↓
吸引更多使用者
    ↓
使用者付费
    ↓
激励更多创作者
    ↓
创作更多配置
    ↓
（循环增长）
```

**结果：** 配置越多 → 价值越大 → 后来者无法超越

---

## 🛡️ 为什么大厂不做？

### 1. 不是核心业务

```
Cursor的核心: 编辑器
配置市场: 不是核心，优先级低
```

### 2. 商业模式不同

```
Cursor: 订阅制（高利润率）
市场: 抽成制（低利润率，运营重）
```

### 3. 基因不匹配

```
Cursor: 产品公司
市场: 需要社区/平台基因
```

### 4. 组织架构限制

```
产品团队不会主动做平台
需要完全不同的团队和文化
```

---

## 💰 商业模式

### 收入来源

```
1. 交易抽成（主要）
   月交易额$100K
   → 平台收入$20K

2. 订阅服务（辅助）
   创作者Pro: $29/月
   企业版: $299/月

3. 增值服务
   配置定制、培训、咨询
```

## 📊 对比：工具 vs 市场

| 维度 | 工具定位 | 市场定位 |
|-----|---------|---------|
| **核心价值** | 功能强大 | 连接供需 |
| **竞争对手** | Cursor/Codex | 无直接竞争 |
| **护城河** | 技术（弱）| 网络效应（强）|
| **与大厂** | 竞争 | 互补 |
| **增长方式** | 产品迭代 | 社区增长 |
| **盈利模式** | 订阅 | 抽成+订阅 |

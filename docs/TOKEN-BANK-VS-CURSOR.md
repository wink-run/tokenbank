## 💡 4个核心用户群体

### 1. 小团队/创业公司（3-15人）**← 首要目标**

**痛点：**
```
❌ 新人配置环境花半天
❌ 每个人配置不同，效率参差不齐
❌ 月底账单爆表，不知道钱花哪了
```

**Token Bank解决：**
```
✅ 10分钟完成新人配置（vs 4小时）
✅ 团队配置统一管理，一键推送最佳实践
✅ 透明账本：按人/按项目/按工具查看成本
✅ 自动优化：识别异常使用，建议降级模型
```

**价值：效率提升30%，成本降低40%**  
**付费意愿：$99/月（高）**

---

### 2. 自由职业者/Solopreneur

**痛点：**
```
❌ 预算有限（$100-500/月），但需求复杂
❌ 想用Opus/GPT-5/Gemini，但每个都要订阅
❌ 不同任务需要不同模型，手动切换太麻烦
```

**Token Bank解决：**
```
✅ 智能路由：代码用Sonnet，文档用Haiku，Debug用Groq
✅ 按需付费：用10次Opus=$3，不用订阅$20/月
✅ 预算控制：设置每日预算，超额自动降级
✅ 共享小组：5人共享$100额度，每人省50%
```

**价值：质量不变，成本省60%**  
**付费意愿：$29/月（中）**

---

### 3. 学生/学习者

**痛点：**
```
❌ Cursor $20/月 = 生活费1/5，买不起
❌ 免费额度很快用完
❌ 想学AI但被经济门槛挡住
```

**Token Bank解决：**
```
✅ 本地模型优先：Qwen、DeepSeek等免费模型
✅ 学习小组：50个学生每人出$5，共享$250额度
✅ 积分激励：分享配置获得积分换API额度
✅ 社区互助：帮助他人获得免费额度
```

**价值：0成本用AI，培养未来付费用户**  
**付费意愿：$0-5/月（低，但量大）**

---

### 4. 企业开发团队（50-500人）

**痛点：**
```
❌ 代码不能发到外网（合规要求）
❌ 公司有自研模型，但Cursor接不进来
❌ 需要审计日志、权限管理、成本分摊
```

**Token Bank解决：**
```
✅ 私有部署：数据不出内网
✅ 自定义模型：接入企业自研LLM
✅ 完整审计：谁/何时/问了什么/用了哪个模型
✅ 权限管理：研发用GPT-4，实习生用Qwen
✅ 成本分摊：按部门/按项目内部结算
```

**价值：满足合规，深度定制**  
**付费意愿：$5K-50K/月（极高）**

## 🎉 总结

### Cursor是什么？

> Cursor是个人AI代码编辑器  
> 服务单个开发者  
> 追求编辑体验

### Token Bank是什么？

> Token Bank是AI能力的组织和分配平台  
> 服务团队、个人、学生、企业  
> 追求协作效率和成本优化

### 核心差异？

> Cursor是"私家车"（自己开，自己维护）  
> Token Bank是"滴滴打车"（按需使用，灵活调度，成本共享）

### 竞争关系？

> 不是竞争，是互补  
> Cursor提供编辑器  
> Token Bank提供配置管理和智能路由  
> 用户可以同时用两者

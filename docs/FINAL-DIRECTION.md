# Token Bank 最终定位

## 🎯 一句话

**AI Agent的外包市场 = 任务外包，不是配置出售**

---

## 💡 核心模式

### ❌ 不是

```
"导出配置，一键安装"

问题：
→ 用户获得完整配置
→ 可以无限使用
→ 可以复制给别人
→ 创作者只收一次钱
→ IP容易泄露
→ 无法防止盗版

类比：卖菜谱
```

### ✅ 是

```
"调用Agent，按次付费"

模式：
→ Agent运行在平台
→ 用户只能调用
→ 每次调用都付费
→ 配置永远不给用户
→ 创作者持续收益
→ 技术上无法盗版

类比：餐厅（配方保密，按次收费）
```

---

## 🏗️ 用户体验

### 用户在Cursor里

```
输入：
"@代码审查专家 审查这段代码
[粘贴代码]"

Token Bank响应：
"正在调用...
预估成本: $1.20
[确认使用]"

30秒后：
"审查完成！
发现3个问题...

本次费用: $1.15"
```

**用户看不到：**
- Agent用的什么模型
- Prompt怎么写的
- 路由规则是什么

**用户只关心：**
- 结果好不好
- 多少钱
- 快不快


### 2.2 势力系统（圈子/联盟）

| 势力 | 特色 | 对应概念 |
|---|---|---|
| **魏 · 霸业** | 强大算力、快速响应 | 高性能模型、低延迟 |
| **蜀 · 仁义** | 本地优先、隐私安全 | 本地Ollama、数据不出门 |
| **吴 · 江东** | 免费为主、灵活变通 | 免费API、轻量化 |
| **群雄 · 自立** | 社区共享、互助互利 | 社区分享网络 |

- 默认阵法偏好
- 推荐武将池
- 势力专属皮肤
- 联盟福利

## 4. 交互流程设计

### 4.1 招募武将（启用流程）

```
1. 【发现】
   用户在"募兵榜"看到推荐武将
   → 显示武将卡牌、属性、技能预览

2. 【招募】
   点击"招募入营"
   → 播放招募动画（武将行礼入营）
   → 提示"诸葛亮已入营！"

3. 【授印】
   选择授印给哪个主公（Cursor/Claude Code）
   → 显示授印动画（授予印绶）
   → 生成口令卡

4. 【口令卡】
   ┌──────────────┐
   │ 点将口令      │
   │              │
   │ "请诸葛亮出战  │
   │  审查代码"    │
   │              │
   │ [复制] [前往战场]│
   └──────────────┘

5. 【首战】
   用户在Cursor中说出口令
   → 诸葛亮出战
   → 完成任务
   → 获得"首战告捷"成就
   → 记录战报
```

### 4.2 点将出战（调用流程）

```
用户说: "请诸葛亮审查代码"
    ↓
模型识别点将意图
    ↓
tb_list_resources(type="assistant", query="诸葛亮")
    ↓
tb_get_resource(name="诸葛亮")
    ↓
返回: 武将信息 + 技能 + 装备
    ↓
模型按武将soul执行
    ↓
记录战报:
- 武将: 诸葛亮
- 技能使用: 锦囊妙计
- 阵法: 八卦阵
- 消耗: 3500T
- 结果: 胜利
    ↓
显示息票（战果小卡片）:
"诸葛亮出战告捷！
 消耗粮草: 35  获得军功: +12"
```

### 4.3 布阵（路由设置）

```
1. 用户进入"阵法图谱"
2. 选择战场类型（日常/紧急/大战）
3. 推荐阵法：
   - 日常: 偃月阵（省钱）
   - 紧急: 锋矢阵（速度）
   - 大战: 八卦阵（本地）
4. 自定义阵法:
   [本地Ollama] → [免费API] → [社区援军] → [付费雇佣]
5. 保存并应用
```

### 4.4 援军系统（社区分享）

```
【请求援军】
1. 本地武将体力不足或无合适武将
2. 点击"请求援军"
3. 显示可用援军列表（社区节点）
4. 选择援军
5. 消耗军功，援军出战
6. 记录援军战报

【派遣援军】
1. 选择闲置武将
2. 设置"可派遣为援军"
3. 其他联盟成员请求时自动派遣
4. 获得军功奖励
5. 查看援军战报"今日助战3次，获军功+67"
```

## 5. 游戏化元素

### 5.1 成就系统

| 成就 | 获得条件 | 奖励 |
|---|---|---|
| 🏅 初出茅庐 | 首次招募武将 | 新手军功+50 |
| 🏅 初战告捷 | 首次点将成功 | 解锁高级武将 |
| 🏅 百战名将 | 单个武将出战100次 | 武将升星 |
| 🏅 节俭军师 | 累计节省10000 Token | 解锁偃月阵 |
| 🏅 援军统帅 | 派遣援军50次 | 联盟声望+100 |
| 🏅 八阵图师 | 收集所有阵法 | 特殊称号 |
| 🏅 五虎上将 | 同时拥有5个五星武将 | 专属皮肤 |
| 🏅 卧龙凤雏 | 招募诸葛亮和庞统 | 组合技能 |

### 5.2 武将升级系统

```
武将使用次数 → 经验值 → 升级 → 强化属性

升级效果:
- 1星 → 2星: 基础能力 +10%
- 2星 → 3星: 解锁第二技能
- 3星 → 4星: 基础能力 +20%
- 4星 → 5星: 解锁终极技能，可装备第三件装备
```

### 5.3 每日任务

```
每日军令:
☐ 点将出战3次 (军功+10)
☐ 使用本地武将5次 (军功+15)
☐ 派遣援军1次 (军功+20)
☐ 完成代码审查 (军功+25)
```

## 8. 技术实现要点

### 8.1 数据模型扩展

```javascript
// 武将数据结构
interface General {
  id: string;
  name: string;           // 三国武将名
  originalModel: string;  // 实际模型名
  faction: 'wei' | 'shu' | 'wu' | 'qun';
  stars: 1 | 2 | 3 | 4 | 5;
  
  // 属性
  attributes: {
    power: number;      // 武力（速度）
    intelligence: number; // 智力（准确度）
    leadership: number;   // 统帅（并发）
    stamina: number;      // 体力（配额）
  };
  
  // 技能（Skills）
  skills: string[];
  
  // 装备（MCP/Prompt）
  equipment: {
    weapon?: string;
    armor?: string;
    mount?: string;
  };
  
  // 统计
  stats: {
    battles: number;      // 出战次数
    wins: number;         // 胜利次数
    experience: number;   // 经验值
    lastBattle: Date;     // 最后出战
  };
}

// 阵法数据结构
interface Formation {
  id: string;
  name: string;           // 阵法名（八卦阵等）
  type: 'defense' | 'offense' | 'balance';
  strategy: RouteStrategy; // 对应路由策略
  description: string;
  visualPattern: string[][];  // 阵型图案
}

// 战报数据结构  
interface BattleReport {
  id: string;
  timestamp: Date;
  general: string;        // 武将
  formation: string;      // 阵法
  battlefield: string;    // 战场（场景）
  
  process: {
    step: number;
    action: string;       // 使用技能/装备
    cost: number;         // 粮草消耗
  }[];
  
  result: {
    success: boolean;
    merit: number;        // 获得军功
    cost: number;         // 消耗粮草
    duration: number;
  };
}
```

### 8.4 兼容性设计

```javascript
// 保持原有功能不变，仅改变呈现
class ModelAdapter {
  constructor(model, theme) {
    this.model = model;
    this.theme = theme;
  }
  
  getDisplayName() {
    if (this.theme === 'sanguosha') {
      return this.mapToGeneral(this.model);
    }
    return this.model;
  }
  
  mapToGeneral(modelName) {
    const mapping = {
      'claude-sonnet-4': '诸葛亮',
      'gpt-4': '司马懿',
      'deepseek': '姜维',
      // ...
    };
    return mapping[modelName] || modelName;
  }
}
```

## 12. 与现有产品的关系

### 12.1 这不是替代品

三国杀世界观是原Token Bank的**主题皮肤+游戏化增强**：

- ✅ 所有原功能保持不变
- ✅ 用户可选择启用/关闭三国主题

| | 专业模式 | 三国模式 |
|---|---|---|

| 游戏化 | 无 | 成就、升级、羁绊 |

三国杀世界观能带来的独特价值：

1. **降低学习门槛** - "点将出战"比"API调用"更好理解
2. **提升趣味性** - 游戏化元素让AI工具使用变有趣

4. **文化认同感** - 中国用户对三国文化有天然亲近感
5. **社交属性** - 联盟、援军等社交玩法更自然

## 13. 风险与应对

| 风险 | 影响 | 应对方案 |
|---|---|---|
| 过度游戏化影响专业性 | 企业用户流失 | 保持专业模式，主题可切换 |
| 三国题材版权问题 | 法律风险 | 使用历史人物，避开游戏版权 |
| 美术成本高 | 开发周期长 | 分阶段实施，先基础后精美 |
| 海外用户不理解 | 国际化受阻 | 保留英文原版，三国版仅中文 |
| 武将名称与模型对应混乱 | 用户困惑 | UI清晰标注实际模型名 |

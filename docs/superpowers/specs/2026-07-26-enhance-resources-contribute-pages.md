# 资源页和贡献页强化方案

日期: 2026-07-26  
核心洞察: **"从交易页和资源页，应该强化画像以及分享"**

---

## 💡 用户的关键指导

### 现状分析

```
Token Bank现有两个核心页面：

1. Resources页（资源页）
   - 展示：用户的Prompts、Skills、Assistants
   - 功能：管理、使用、推荐
   - 缺少：个人画像、分享

2. Contribute页（贡献/交易页）
   - 展示：贡献算力、模型、智能体
   - 功能：共享到社区/圈子
   - 缺少：个人画像、对外分享

问题：
❌ 没有突出个人品牌
❌ 没有一键分享功能
❌ 资源展示缺乏三国化
❌ 无法对外传播
```

---

### 应该做什么

```
强化画像：
✅ 在两个页面顶部展示个人画像
✅ 三国化：主公形象、战绩、称号
✅ 个人品牌建设

强化分享：
✅ 一键生成个人名片
✅ 分享武将阵容到微信
✅ 分享个人主页链接
✅ 病毒式传播
```

## 🎯 个人画像设计

### 画像内容

```
个人画像包含：

1. 基础信息
   - 头像（可选三国武将风格）
   - 昵称
   - 势力（蜀/魏/吴/群，可选）
   - 称号（根据活跃度自动生成）

2. 星级
   - 根据以下因素计算：
     * 活跃天数
     * 资源数量
     * 使用次数
     * 好评率
     * 贡献积分
   - 显示为⭐⭐⭐⭐⭐（1-5星）

3. 战绩统计
   - 麾下武将数量
   - 出战次数
   - 胜率
   - 服务用户数（如果有分享）

4. 收益统计（贡献者）
   - 本月积分
   - 本月收益
   - 总收益
   - 排名

5. 个人印记
   - 一句话介绍（用户自定义）
   - 例如："用AI提升10倍开发效率"
```

# Token Bank 0.7.0

这一版把 Token Bank 做成你身边的智能体工作台。界面按日常使用重排，智能管家开始替你盯资产和任务，Docker 与网页打开的是同一套完整能力，官网和雇佣市场一起换新。

## 全新界面

网关、模型、资产、盘点和交易，都收成「先看状态，再点进去」。

- **网关**：通用、专业、外部智能体和路由分栏摆开。专业智能体按它跑在哪个应用上成组，每个智能体有自己的接口钥匙，试一下就在那一行。
- **模型**：按厂商收成一排芯片，失败原因写在旁边，路由和备用链留在同一页。
- **资产**：有问题的排在最前。智能体模板写清投射到哪、缺哪些技能，点一下就能去改。
- **盘点**：多台设备合成一张账。费用、用量和「这台是本机」放在一起，对得上。
- **手机**：列表、对话和网关在小屏幕上也能完整操作。

## 智能管家

侧边栏上多了一位管家。它看着资产、投射和正在跑的任务：能自己做的安全修复直接做完，拿不准的在对话里问你。

- 有问题的资产点「看一下」，管家用和资产页相同的入口去处理。
- 先按你教过的规则办，规则盖不住再用判断。你纠正一次，它就记住。
- 雇佣来的任务先过安全检查。
- 回复可以是表格、列表和图表，数字不用在长文里翻。

## Docker：完整桌面能力

容器里跑的是和桌面版同一套工作台。浏览器打开就能用网关、资产、游乐场和会话，Claude Code 等命令行智能体在容器里纳管、投射、执行。

- 技能、MCP、HTTP API 和本地命令都可以在容器里配置。
- 智能体接口带着钥匙，外部智能体可以注册进来接任务。
- 默认工作目录是 `/workspace`，打开就能让智能体看项目。

## 网页版上线

没有安装包也能开始。网页版按地址栏进入，刷新停在原页，链接可以发给别人。

分享出去的智能体有自己的网页名片：介绍、雇佣次数和怎么用，打开就能看。

## 官网与雇佣市场

首页用六层架构讲清楚 Token Bank 在整条链路上的位置。交易页分成买、卖、收支。

- 上架时为每一项选定公开，或只给哪些圈子。
- 雇佣后的智能体出现在游乐场，和本机应用、专业智能体放在同一个「和谁说话」里。
- 卖页能看到近 7 天收益和正在为别人执行的任务。

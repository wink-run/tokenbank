## Changelog — v0.7.0 (2026-11-19)

### ✨ 全新界面
网关、模型、资产、盘点和交易按日常使用重排：先看状态，点进去再看细节。

- 网关分成通用、专业、外部智能体和路由。专业智能体按所在应用成组，每个智能体有自己的接口钥匙，试一下就在那一行
- 模型按厂商收成芯片，失败原因写在旁边，路由和备用链放在同一页
- 资产页把有问题的排在最前，智能体模板写清投射目标和缺的技能
- 盘点把多台设备合成一张账，并标出本机

### ✨ 智能管家
侧边栏上的管家看着资产、投射和正在跑的任务。能自己做的安全修复直接做完，拿不准的在对话里问你。

- 有问题的资产可以交给管家，它用和资产页相同的入口去处理
- 先按你教过的规则办；纠正一次，对应规则就记住
- 雇佣来的任务先过安全检查
- 回复可以是表格、列表和图表

### ✨ Docker 完整桌面版
容器里跑的是和桌面版同一套工作台。浏览器打开就能用网关、资产、游乐场和会话。

- 命令行智能体在容器里纳管、投射、执行
- 技能、MCP、HTTP API 和本地命令都可以在容器里配置
- 智能体接口带着钥匙，外部智能体可以注册进来接任务

### ✨ 网页版与雇佣市场
没有安装包也能进市场。按地址栏进入，刷新停在原页，链接可以分享。市场分成买、卖、收支。

- 官网首页用六层架构说明 Token Bank 在链路中的位置
- 分享出去的智能体有自己的网页名片，打开就能看介绍和雇佣
- 上架时为每一项选定公开，或只给指定圈子
- 雇佣后的智能体出现在游乐场，和本机应用放在同一个「和谁说话」
- 卖页能看到近 7 天收益，以及正在为别人执行的任务

### 🐛 Fixes
- 网关模型列表只展示个人页已登记的付费源
- 手机上的网关、资产和游乐场可以完整操作
- Docker 中的 Claude Code 登录与桌面版对齐
- 覆盖无效的 Claude settings.json 之前先备份
- 探测失败时保留已经上架的智能体

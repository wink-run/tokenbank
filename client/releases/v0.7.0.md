## Changelog — v0.7.0 (2026-11-19)

### ✨ Features
- 界面重排：网关、模型、资产、盘点、交易统一成先看状态，点进去再看细节
- 网关分成通用、专业、外部智能体和路由；专业智能体按所在应用成组，每个智能体有自己的接口钥匙
- 模型按厂商收成芯片，失败原因写在旁边，路由和备用链放在同一页
- 资产页把有问题的排在最前，智能体模板写清投射目标和缺的技能
- 盘点把多台设备合成一张账，并标出本机
- 引入智能管家：看资产、投射和任务，能自己做的安全修复直接做完，拿不准的在对话里问
- 有问题的资产可以交给管家处理；纠正一次，对应规则就记住
- 雇佣来的任务先过安全检查；管家回复可以是表格、列表和图表
- Docker 支持完整桌面版：浏览器里使用网关、资产、游乐场和会话，容器内纳管命令行智能体
- 容器里可以配置技能、MCP、HTTP API 和本地命令，智能体接口带钥匙
- 上线网页版：按地址栏进入，刷新停在原页，链接可以分享
- 分享出去的智能体有网页名片，打开就能看介绍和雇佣
- 官网首页用六层架构说明 Token Bank 在链路中的位置
- 雇佣市场分成买、卖、收支；上架可选公开，或只给指定圈子
- 雇佣后的智能体出现在游乐场，和本机应用放在同一个「和谁说话」

### 🐛 Fixes
- 网关模型列表只展示个人页已登记的付费源
- 手机上的网关、资产和游乐场可以完整操作
- Docker 中的 Claude Code 登录与桌面版对齐
- 覆盖无效的 Claude settings.json 之前先备份
- 探测失败时保留已经上架的智能体
